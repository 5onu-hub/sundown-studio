# 🌅 Sundown Studio

A modern and visually engaging **studio website** built with React.js, inspired by the creative and immersive design style of Sundown Studio.

The project focuses on smooth animations, responsive layouts, reusable React components, and an interactive user experience.

## ✨ Features

* 🎨 Modern and creative UI
* ⚛️ Built with React.js
* 🧭 Multi-page navigation using React Router
* 🎬 Smooth animations and transitions
* 🖱️ Interactive hover effects
* 📱 Responsive design
* 🧩 Reusable React components
* 🖼️ Image and video integration
* 📄 Custom pages for Home, Work, Studio and Contact
* ❌ Custom Not Found page

## 🛠️ Tech Stack

* **React.js**
* **JavaScript**
* **CSS3**
* **React Router DOM**
* **GSAP**
* **Vite**

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/sundown-studio.git
```

### 2. Navigate to the project

```bash
cd sundown-studio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.
